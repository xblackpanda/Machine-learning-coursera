# Machine Learning Laboratory

## Description

โฟลเดอร์นี้จัดทำขึ้นเพื่อใช้ประกอบการศึกษาและการเรียนรู้ด้าน **Machine Learning** โดยรวบรวมตัวอย่างโค้ดสำหรับการทดลองสร้างโมเดล Regression และ Classification รวมถึงการเปรียบเทียบประสิทธิภาพของโมเดลในแต่ละรูปแบบ

เนื้อหาภายในประกอบด้วยตัวอย่างการใช้งานไลบรารี **Scikit-learn**, **Pandas**, **NumPy** และเครื่องมือที่เกี่ยวข้อง เพื่อศึกษาขั้นตอนการเตรียมข้อมูล การฝึกสอนโมเดล การประเมินผล และการแสดงผลลัพธ์ในรูปแบบต่าง ๆ

**วัตถุประสงค์**

* ศึกษาหลักการของ Machine Learning
* ฝึกใช้งานอัลกอริทึม Regression และ Classification
* เรียนรู้การประเมินประสิทธิภาพของโมเดล
* ใช้เป็นสื่อประกอบการเรียน การทดลอง และการทำแบบฝึกหัด

> **หมายเหตุ**
>
> โครงการนี้จัดทำขึ้นเพื่อวัตถุประสงค์ทางการศึกษา การเรียนรู้ และการทดลองเท่านั้น **ไม่มีเจตนาเพื่อแสวงหาผลกำไรหรือใช้ในเชิงพาณิชย์** ผู้จัดทำไม่รับรองว่าโค้ดหรือผลลัพธ์เหมาะสำหรับการใช้งานในระบบจริงโดยตรง ควรนำไปศึกษาและพัฒนาต่อยอดตามความเหมาะสม
